# Hive — Development TODO

**Source of truth:** `docs/hive.md` (Portuguese). Every task cites the decisions (`#N`, `D#`) it implements; read them before starting the task.
**Visual reference:** `docs/prototype/` (read `docs/prototype/README.md` first).
**Rules:** `CLAUDE.md`.

## How to use this file

1. Work **top to bottom**, one task at a time. Do not start a task whose dependencies are not checked.
2. Before a task: read the cited decisions in `docs/hive.md`. After a task: all quality gates green (CLAUDE.md), then tick the box and add the branch name next to it.
3. **⏸ Checkpoint** = stop and wait for the human. Do not continue past a checkpoint on your own.
4. If a decision is unclear, missing, or contradicted by reality: stop and ask. Never change a decision yourself.
5. Finished stages move word for word to `docs/history/` and keep one line under "Earlier stages". A default a task takes (a choice `docs/hive.md` does not settle, "pending human review") also gets a row in the "Defaults ledger" with status `pending`.

  - **stderr classified, each case with its message:**
    - unknown or changed host key: "run `ssh <alias>` once in a terminal to check and accept its key". Hive never writes `known_hosts`;
    - authentication: a passphrase or password was asked, so "add the key to your ssh agent";
    - network;
    - unsupported platform;
    - another version (Q8): both versions shown, with "Restart the remote service (ends N terminals)" or "Stay disconnected". Restart runs a new `hive bridge --replace`, which ends the running service (SIGTERM to the lockfile's holder) and starts its own.
  - **Reconnect:** a ladder of 1, 2, 5, 10 and 30 s, then every 30 s while the host has kept terminals. No retry after a host key, authentication, platform or version error. An immediate try on wake (`NSWorkspaceDidWakeNotification`).
  - **Settings:** the hosts list (`remote.hosts`) and `remote.keep_minutes` live in the local service's settings.
  - **Tests:**
