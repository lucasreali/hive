## Stage 17 — macOS as the main platform

Created 2026-10-19 at the human's request: the human now uses (and develops) Hive 100% on an Apple Silicon MacBook (macOS 26) instead of Windows + WSL. Five research agents audited the service and app (`crates/hive`, `src-tauri`), the frontend's macOS UX, the dev workflow (CLAUDE.md, scripts, hooks, CI), the platform's requirements (signing, TCC, limits, power, menus) and what other tools offer (Conductor, Cursor, Zed, Warp, Ghostty, iTerm2, cmux, Superset, Claude Code desktop, Orca, Emdash…). Their findings, with evidence, are condensed into the tasks below; tasks that need a decision first say which. Run with `/stage 17`.

**Decisions for the human before the stage starts** (nothing below changes `docs/hive.md`; the human updates it):

- **D17.0 Windows support.** Keep Windows + WSL as a supported platform (CI `windows.yml`, NSIS release, 16.4) or freeze it? Recommendation: keep it building in CI, but stop adding Windows-only work. `docs/hive.md` "Contexto sobre mim", "Situação atual" and #39 ("segunda plataforma") describe Windows as the main one.
- **D17.1 Signing (#39).** Ad-hoc signing has three costs on macOS 15/26: (a) every update changes the code identity, so TCC grants (Documents/Desktop/Downloads, Full Disk Access) silently stop working and are asked again; (b) Gatekeeper's Control-click bypass is gone, first launch needs Privacy & Security → Open Anyway; (c) a quarantined app runs **translocated** (seen on this Mac: `hive-app` runs from `/private/var/folders/…/AppTranslocation/…`), where the updater cannot replace it. Options: **$99/yr Developer ID + notarization** (fixes all three; required for a Homebrew cask since Homebrew 5 deprecated `--no-quarantine`), **a free self-signed certificate** kept in CI (fixes (a) only), or keep ad-hoc and document the steps. Recommendation: Developer ID. *Decided by the human 2026-11-06: a self-signed certificate, built in 25.14.*
- **D17.2 macOS keys (#35, #53).** Proposed macOS-only additions, none reaching the shell (Cmd never does): ⌘W closes the active tab (not the window), ⌘1–9 and ⇧⌘[ / ⇧⌘] switch tabs, ⌘F searches the focused terminal, ⌘K clears it, ⌘← / ⌘→ / ⌘⌫ send line start / end / kill-line, ⌘= / ⌘- / ⌘0 change the terminal font size, ⌘, opens Settings. **F8 is Play/Pause on MacBook keyboards** unless Fn is held: pick an alternative for "next pending agent" (proposal: ⇧⌘J, F8 kept).
- **D17.3 Red button and ⌘Q.** Today ⌘Q quits at once and skips the close guard (#47, risk 9); the red button quits. Proposal: ⌘Q goes through the same confirmation; the red button keeps quitting (Hive's service lives with the app, #14) rather than the Mac's hide-on-close.
- **D17.4 Files dropped from Finder (#57).** Terminal/iTerm users drop a file on the terminal to paste its quoted path. Allow it on macOS (Tauri drag-drop on, only onto a terminal)?
- **D17.5 Runtime folder (#39, risk 9.7).** Move the socket/lock from `/tmp/hive-<uid>` to `$TMPDIR/hive` (per-user, mode 0700, survives macOS's `clean-tmps` of 3-day-old `/tmp` entries).
- **D17.6 Gates on the Mac (D6, 5.11).** The WSL-VM reasons (`CARGO_BUILD_JOBS=3`, memory watchdog, heavy gates only in CI) do not hold on a 10-core, 24 GB Mac. Proposal: CI stays the authority; locally allow `CARGO_BUILD_JOBS` up to 6 and llvm-cov of the macOS cfg; mutants still one at a time.
- **D17.7 New dependencies (rule 3), each asked again at its task:** Playwright WebKit browser (17.3), `tauri-plugin-window-state` and `tauri-plugin-single-instance` (17.18), an IOKit binding for the power assertion (17.17, or plain `extern "C"` with no crate), `@xterm/addon-search` (17.21), `tauri-plugin-global-shortcut` (proposal list).
